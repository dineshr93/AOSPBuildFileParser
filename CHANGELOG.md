## [1.0.0] - 2026-05-28

### Added
- Initial release of AOSP Build File Parser
- Full AOSP tree scanning for `.bp` and `.mk` files
- Variable resolution in module properties
- Defaults chain inheritance resolution
- Transitive dependency resolution via BFS
- Source file path extraction
- Structured JSON registry output
- GitHub Action for automated releases
- Pre-built binaries for Linux, macOS, and Windows
- Comprehensive Makefile with build, test, and demo targets
